# Security Policy

## Supported Versions

Security updates are applied to the latest deployed version of [sanyi.dev](https://sanyi.dev).

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the details to [business.sanyi@gmail.com](mailto:business.sanyi@gmail.com).

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You can expect a response within 7 days.
