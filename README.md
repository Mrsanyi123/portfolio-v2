# Sanyi — Portfolio

Personal portfolio of **Sanyi Diriba** — developer, founder, and content creator.

## Tech Stack

Next.js 14 · TypeScript · Tailwind CSS · Framer Motion · Vercel

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Configuration

Update `src/data/resume.tsx` with your personal information.

Optional environment variables are documented in `.env.example`.
